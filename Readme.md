# FreeCAD model of a switch Panel for Ducato Cup Holder
This model is meant for a 3D printed panel for the cup holder. 

### Mechanical properties
- Size: 65mm x 45mm
- 2mm thick frontpanel
- 5mm thick body 
- 4 locking lugs
- modify the design of the locking lugs only in `Rastnase1`

### Cut outs
- 2 x Marquardt Series 1830 switches (30.5mm x 11mm)
- USB-A socket (extension for radio USB connector) with size 22mm x 13mm
- parameters of cut-outs defined in spreadsheet "Dimensions"
 
### Material for 3D Print
- laser sintered (SLS) Nylon (see images)
- PLA requires much stronger locking lugs
